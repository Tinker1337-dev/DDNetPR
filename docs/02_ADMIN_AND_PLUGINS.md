# Администрирование и встроенные плагины DDNetPR v11.7.0 LTS

## 1. Первичная настройка прав владельца
1. Зайдите на сервер и зарегистрируйте аккаунт: `/register <логин> <пароль> <пароль>` (вход: `/login <логин> <пароль>`).
2. Получите роль `owner` по RCON-паролю из `autoexec_server.cfg`:
   `!auth_admin <rcon_пароль>`
3. Выдача ролей другим игрокам: `!setrole <ник> <owner|admin|mod|helper|user>`.

## 2. Встроенные публичные плагины
- **`plugin_hub`**: `!help` (список команд), `!plugins` (активные плагины), `!modules`.
- **`plugin_city`**: экономика аккаунтов — `!bal`, `!top`, `!dice <ставка>`, `!pay <ник> <сумма>`, `!givecoins <ник> <сумма>` (для стаффа).
- **`plugin_potato`**: мини-игра «Горячая картошка» (`!potato`).

## 3. Встроенные стафф-плагины
- **`plugin_mod`**: модерация и управление — `!hud`, `!ids`, `!staff`, `!warn`, `!mute`, `!kick`, `!check`, `!ban`, `!freeze`, `!pm` (менеджер плагинов: `!pm list`, `!pm reload <имя>`, `!pm stop <имя>`, `!pm start <имя>`).
- **`plugin_perf`**: мониторинг нагрузки CPU/IPC (`!perf`, `!online`).
- **`plugin_super`**: админ-способности (`!super` / `!god` — полёт, кластерные взрывы, фриз-луч).
- **`plugin_sunstrike`**: удар молнией/лазером по позиции (`!sunstrike`).
- **`plugin_brush`**: рисование объектами на карте (`!brush`).
- **`plugin_build_tee`**: спавн визуальных ти-декораций (`!build`).
- **`plugin_reboot`**: безопасная перезагрузка сервера с оповещением (`!reboot`).

## 4. Горячее обновление плагина без кика игроков
Положите новый скомпилированный бинарник `plugin_<name>` в папку `plugins/` — менеджер автоматически подхватит его или выполните `!pm reload plugin_<name>` в чате.
